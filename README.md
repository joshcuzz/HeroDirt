# Hero Dirt

Experimental mountain-bike trail-condition forecasting for the San Gabriel Mountains.

## Live maps

### [Open Hero Dirt Forecast](https://joshcuzz.github.io/HeroDirt/)

Trail conditions and forecasts from now through +120 hours.

### [Open Hero Dirt Explorer](https://joshcuzz.github.io/HeroDirt/explorer.html)

Explore the soil, terrain, vegetation, precipitation, and modeled hydrologic variables used by Hero Dirt.

---

Hero Dirt is an experimental three-layer soil-moisture model using NASA SMAP soil moisture, NOAA MRMS precipitation, National Weather Service forecasts, and spatial soil, terrain, and vegetation information.
